=== description
Review a GitHub pull request, a local Git range, or a PR's local commits against QuestDB coding standards. Use when asked to review a PR, given a PR number or URL, given --range=<base>..<head>, or given both, optionally with a review level 0..3. Performs an adversarial, blocking, evidence-gated code review.
=== argument_hint
[PR number or URL] [--range=<base>..<head>] [--level=0..3] [--block-at=critical|high|medium|low] [--body=<file>] [--prior=<file>,...]
